# Python To-Do App

A beginner-friendly To-Do App built using Python.

## Features
- View Tasks
- Add tasks
- Remove tasks
- Productivity percentage
- Pie chart visualization using matplotlib

## Technologies Used
- Python
- Matplotlib

## Future Improvements
- GUI
- Dark mode
- File saving
- Deadlines
